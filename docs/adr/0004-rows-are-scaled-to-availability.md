# A row's full height is that Person's Availability

Every row is drawn at the same height, and its full height means that Person's Availability, so 100% always means their own Capacity - an 80% person at 60% holds 0.48 FTE. The alternatives were a row fixed at 1.0 FTE with the Availability drawn inside it as a ceiling, which makes rows comparable across people but puts a permanent unavailable band on every part-timer's row, and expressing shares in FTE, which adds a second unit wherever capacity appears. One scale per row, with the percentage as the unit people say, was chosen for v1.
