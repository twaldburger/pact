# The Timeline item is an Assignment, not a Project on a row

A rectangle on the Timeline is an Assignment - one Project, one Person, a start, an end and an Allocation - rather than a Project occupying a row directly. This is what lets one Project sit on several People at once with different ranges and shares, which is what shared work looks like; placing the Project itself on the row would require a copy per Person and would leave the copies to drift apart.
